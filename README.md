# Плагин по работе с шаблонами
 Данный плагин представляет собой расширение, которое позволяет удобно работать с шаблонами кода.

## Возможности плагина на данный момент:

* Cоздание новых шаблонов и редактирование их через текстовый редактор.
* создание или изменение шаблона через выделенный код в редакторе.
* Можно через горячие клавиши выбрать и вставить шаблон.
* Плагин поддерживает динамические параметры шаблона.
* удаление шаблонов через горячие клавиши.
* Просмотр статистики использования шаблонов.
* Группировка шаблонов по языкам, пользовательским категориям и избранному.
* Предпросмотр шаблона перед вставкой.
* Экспорт и импорт шаблонов в формате .json.


> Tip: Many popular extensions utilize animations. This is an excellent way to show off your extension! We recommend short, focused animations that are easy to follow.
